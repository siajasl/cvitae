## Overview

This folder contains assets for generating a **single-page CV website**.

## Rules

- The website MUST be creative and unique
- The website MUST be SEO optimised
- The website MUST be AI optimised
- The website MUST be web accessibile
- The website MUST be i18n optimised:
  - It MUST support English, French and Chinese

## Directories

- /assets
  - static assets referenced from html code
  - CV JSON file (generated by AI) 
  - CV PDF file (generated by AI)
  - Headshot image(s)

- /fonts
  - custom fonts referenced from html code

- /inputs
  - various static files used as inputs for site generation
